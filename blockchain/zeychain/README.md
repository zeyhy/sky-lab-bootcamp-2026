# ZeyChain

ZeyChain is an educational mini blockchain project developed with Python.

The purpose of this project is to understand the fundamental concepts of blockchain technology by implementing a simple blockchain from scratch.

## Features

- Block creation
- SHA-256 hashing
- Previous hash mechanism
- Genesis block
- Transactions
- Pending transactions
- Proof of Work
- Mining
- Blockchain validation
- Command-line interface

## Technologies

- Python
- SHA-256
- Object-Oriented Programming

## How It Works

The basic flow of ZeyChain is:

Transaction
↓
Pending Transactions
↓
Block
↓
Proof of Work
↓
Mining
↓
Blockchain

## Blockchain Structure

Each block contains:

- Index
- Timestamp
- Transactions
- Previous Hash
- Hash
- Nonce

## Project Purpose

This project was created as part of the SKY LAB Bootcamp 2026 blockchain studies to reinforce theoretical knowledge through practical implementation.

## Disclaimer

ZeyChain is an educational blockchain simulation. It is not intended for real financial transactions or production use.
